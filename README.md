# Legal AI Assistant

## Автоматизированное юридическое исследование с проверяемой доказательной базой

---

## 1. Идея проекта

**Legal AI Assistant** — интеллектуальная система для автоматизации первичного юридического исследования.

Цель проекта — не создать ещё один чат с LLM и не заменить профессионального юриста, а автоматизировать основную рутинную часть юридического исследования:

- понять правовой вопрос;
- определить, каких обстоятельств или данных не хватает;
- сформировать поисковую стратегию;
- найти релевантные нормативные документы и судебную практику;
- отобрать наиболее значимые источники;
- извлечь применимые нормы и точные цитаты;
- сопоставить нормы, условия, исключения и судебные позиции;
- найти альтернативные или потенциально противоположные подходы;
- сформировать аргументированный результат;
- автоматически проверить цитаты, реквизиты, ссылки и связь утверждений с источниками;
- показать ограничения и недостаточность доказательной базы.

На выходе юрист получает не список ссылок, а **готовую аналитическую основу для профессиональной оценки и принятия окончательного решения**.

Основной принцип:

> **LLM не является источником права. Источниками являются проверяемые нормативные и судебные документы, из которых система извлекает доказательства.**

---

# 2. Какую проблему решает система

Обычный интернет-поиск помогает найти документы, но значительная часть юридической работы остаётся на пользователе.

После получения результатов юристу приходится:

1. открыть множество документов;
2. определить, какие из них действительно относятся к вопросу;
3. найти нужные статьи и пункты;
4. проверить редакцию документа;
5. установить, действовала ли норма на нужную дату;
6. найти судебную практику;
7. сопоставить различные судебные позиции;
8. извлечь аргументы;
9. проверить реквизиты и ссылки;
10. самостоятельно сформировать аналитическую справку.

Legal AI Assistant автоматизирует именно этот этап.

Система должна выполнять:

**поиск → отбор → извлечение → сопоставление → анализ → проверку → подготовку результата.**

Поэтому проект представляет собой не просто semantic search и не просто RAG.

Это:

> **автоматизированное юридическое исследование с проверяемым результатом.**

---

# 3. Практическая ценность

Система должна сокращать время, которое специалист тратит на первичный анализ большого массива юридической информации.

Например, пользователь задаёт:

> ООО заключило договор. Контрагент нарушил обязательства и причинил убытки. Какие требования могут быть заявлены и какие обстоятельства необходимо доказать?

Legal AI Assistant должен не просто найти несколько страниц с ГК РФ.

Он должен:

1. определить правовые категории вопроса;
2. сформировать поисковый план;
3. найти применимые нормы;
4. определить связанные статьи;
5. найти условия применения нормы;
6. найти исключения и ограничения;
7. найти релевантную судебную практику;
8. сопоставить судебные позиции;
9. извлечь подтверждающие фрагменты;
10. сформировать структурированный результат;
11. проверить, что каждый существенный вывод имеет доказательную опору.

# 4. Что отличает Legal AI Assistant от обычного поиска

| Задача | Обычный поиск | Legal AI Assistant |
|---|---|---|
| Поиск информации | Находит страницы и документы | Формирует поисковую стратегию и выполняет поиск |
| Отбор документов | Пользователь просматривает результаты | Retrieval + metadata filtering + reranking |
| Поиск нужного фрагмента | Пользователь читает документ | Система извлекает релевантные фрагменты |
| Извлечение нормы | Пользователь самостоятельно находит статью | Система извлекает применимые положения и точные цитаты |
| Проверка редакции | Пользователь проверяет дату | Система учитывает версии и даты действия |
| Судебная практика | Отдельный ручной поиск | Отдельный retrieval-контур судебных актов |
| Сопоставление позиций | Ручной анализ | Автоматическое выявление совпадений, различий и альтернативных подходов |
| Формирование результата | Пользователь пишет справку | Система формирует структурированный результат |
| Цитирование | Пользователь копирует цитаты | Evidence Builder извлекает цитаты непосредственно из документов |
| Проверка результата | Ручная | Автоматическая проверка цитат, реквизитов, ссылок и evidence |
| Недостаток данных | Может остаться незамеченным | Система должна сигнализировать о недостаточной доказательной базе |

Главный результат:

> **Система выдаёт не набор ссылок, а результат первичного юридического исследования.**
